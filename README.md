# Logic Agency Site Concept

> **Concept repository only. This is not the production Logic Agency website.**

This repository is an isolated workspace for exploring revisions to Logic Agency's positioning, messaging, information architecture, and visual presentation.

## Separation from production

- The live website source remains in a different repository.
- This repository must never be connected to the production Logic Agency deployment or domain.
- Changes here must not be pushed or copied into the live website without explicit human approval and a separate review process.
- No production deployment configuration or inherited Git remote is included.

## Current concept direction

The homepage explores:

- Supply-chain consulting as the primary position
- Product and retail readiness as a complementary service domain
- Buyer-problem framing in plain language
- Audit and analysis, recommendations and roadmap, then implementation
- Industry-specific expertise rather than broad "CPG" positioning
- Transparent ways to engage without inventing new commercial terms
